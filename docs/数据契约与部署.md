# 数据契约与部署说明

## 窗口接口

原型输入为一分钟聚合的窗口特征；采集硬件需自行提供真实波形、特征与质量指标。`predictive/signals.py` 提供可独立验证的因果滑动滤波、Hann FFT、RMS、峭度及波形质量辅助函数；并未完成采集驱动或完整轴承包络/阶次分析。

| 字段 | 单位或含义 |
|---|---|
| device_id / run_id / sequence | 设备、独立运行段、连续窗口序号；三者联合唯一 |
| timestamp | 采样时间，ISO 8601，包含时区；服务器另存接收时间 |
| rpm / load / ambient_c / mode | 转速 rpm、独立负载比例 0–1、环境温度 °C、模式 drilling |
| vibration_rms / vibration_kurtosis | 仿真振动幅值（示例 m/s²）/ Pearson 峭度，无量纲 |
| current_rms / current_ripple | 电流 RMS / 纹波 RMS，A |
| temperature_rise / temperature_slope | 相对环境温升 °C / 温升斜率 °C/min |
| q_vibration / q_current / q_temperature | 0–1 质量分数；0 表示不可用，不是健康状态 |
| stage / hi_label / rul_hours | 仅仿真训练标签；推理不读取上传的真实标签 |

实际设备须同时保存振动方向、电流测点、传感器量程、校准、采样率、滤波配置和安装记录。当前仿真不是三轴原始波形，特征尺度不能直接迁移至真实设备。

模型使用16个一分钟窗口，只估计当前末时刻输出；每个序列重置 LSTM，不能跨运行段、断包或整窗口全部缺测拼接。输入时间范围与原技术说明的60个秒级窗口不同，是电脑仿真配置，并未证明长周期寿命能力。

质量为0的通道被掩蔽；部分通道缺失可给出标记为降级的研究性风险评分，但不输出 RUL。全部无效、未知模式或工况超出训练范围时输出数据不足。HI 是模型学习的模拟磨损指数，不是实际无故障概率。

## 持久化和维修

SQLite 文件在 `artifacts/maintenance.sqlite3`，包含设备、窗口结果、告警事件、工单与操作审计。事件按设备和运行段合并并可升级严重度。收到确认不会关闭事件；维修记录生成新的运行段，标签进入 pending_review，不自动进入训练集。复测要求同设备新运行段、5个连续有效低风险窗口和稳定负载；通过后关闭事件。

当前基线固定于训练时，不做未经审核的在线更新。工况切换清除证据累计；连续5个低风险窗口恢复监测状态，未复测的持久化事件仍保留。迟到遥测被保存，已存推理记录保持不变；不宣称已实现通用乱序流重算或离线缓存协议。

## API

用 `.venv/bin/python -m uvicorn predictive.api:app --host 127.0.0.1 --port 8000` 启动本地开发 API。

| 方法与路径 | 功能 |
|---|---|
| GET /health | 本地研发服务健康 |
| GET /devices；POST /devices | 列表、绑定设备 |
| POST /telemetry | 批量窗口输入，由服务端推理后存储；重复窗口忽略 |
| GET /devices/{id}/history | 历史记录 |
| GET /events；GET /events/{id} | 事件列表与证据 |
| POST /events/{id}/acknowledge | 确认收到 |
| POST /events/{id}/tickets | 幂等创建工单 |
| GET /tickets | 工单列表 |
| POST /tickets/{id}/repair | 保存维修及证据 |
| POST /tickets/{id}/retest | 通过窗口身份读取服务端保存的推理结果，不能用客户端伪造风险分数关闭事件 |
| GET /models | 模型清单与基线附件 |
| GET /openapi.json | 完整接口结构 |

研发接口没有生产登录、设备权限、MQTT、手机推送及 BLE 驱动，默认只绑定本机；公开部署前需补齐身份和访问控制。网页和 API 共享数据库。

## 模型包和部署边界

模型包包含权重、SHA-256、基线系数与尺度、特征顺序、类别映射、序列长度、单位及运行时。加载使用 PyTorch weights_only 并校验摘要；摘要用于完整性校验，不等于数字签名或可信发布。尚未实现签名 OTA、原子切换与自动回退。

实验包含 LSTM 动态 INT8 量化评估，默认页面使用 FP32 模型；量化不等于整个 Transformer–LSTM 网络已支持 MCU。延迟只测当前 CPU 模型前向，不含采集、FFT、网络传输；峰值 RAM、功耗、硬件保护和原始片段环形缓存待实机实施。
