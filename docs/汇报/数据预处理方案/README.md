## 讲解思路

先把不同传感器数据整理到同一时间窗口，检查缺失、饱和和异常记录；然后分别处理振动、电流和温度，提取有物理意义的信息。振动有效值反映强度，峭度反映冲击，FFT把波形转换为不同频率的组成；电流观察强度和纹波，温度观察相对环境温升和升温速度。

再根据独立检查或数据集原始说明标注故障类别，有可核验依据时才标注损伤程度。先按设备或完整原始记录分组，再划分训练、验证、测试集，目标比例为7:2:1；同一记录的重叠窗口不得跨集合。最后只用训练集计算标准化参数，验证和测试复用这些参数，避免评价结果虚高。

## 与当前项目的关系

当前CWRU预验证已完成振动重采样、窗口切分、去均值、三级Haar小波软阈值降噪及训练集全局标准化。当前分类器输入是降噪振动波形，FFT等特征表用于解释；公开数据未替代自有电动工具电流、温度和实际工况采集。CWRU故障类别是部位标签，不能直接称为真实磨损等级或寿命标签。

完整备注也说明时间同步、电机驱动方式、异常冲击保留、工况标记及分组评价的限制。页面没有页脚、日期和角落补充文字。
