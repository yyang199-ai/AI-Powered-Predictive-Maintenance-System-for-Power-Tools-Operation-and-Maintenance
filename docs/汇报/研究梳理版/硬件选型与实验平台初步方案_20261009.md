# 电钻预测性维护：硬件选型与实验平台初步方案

2026年10月9日导师讨论稿。状态：设计建议，未采购、搭建或实测。候选型号未联网核对当前手册与供货，参数应在选型验收时核查。

## 一、对象、范围与阶段目标

第一对象为一种低压直流电钻，先使用非冲击模式，记录有刷/无刷类型、控制方式、减速结构、轴承型号及可拆检性。第一阶段目标是可靠采集、工况与质量处理、轴承异常识别和误报警控制。真实RUL需要持续退化轨迹与独立失效定义，暂不作为没有数据时的强制首项。

若电钻内部轴承不易拆检、不能获得独立标签或无法稳定连接负载，优先使用可更换轴承的电机—传动台架进行机制验证，再补电钻采集及迁移验证。台架结果不得直接称为真实电钻效果。

## 二、系统总体架构

电钻/传动台架 → 振动、电流、温度及独立转速/负载 → 同步高频DAQ与低频记录 → 电脑原始数据检查、特征、质量和工况参考 → 联合准入与预测 → 告警/复测与证据管理。

电脑CPU用于首阶段推理与实验；现有网页用于展示结果、历史和维修记录。波形采集、短窗预处理、真实质量计算和新特征接入都需开发。边缘网关、MCU、APP和云服务为验证后扩展，不以复杂部署取代诊断证据。

## 三、硬件候选清单与选择依据

|部件|优先配置|经费有限时的候选|应核查的要求|
|---|---|---|---|
|被测设备|一种可固定、可检查的低压直流电钻|可换轴承的电机传动台架先验证|型号、驱动、减速比、轴承及拆检条件|
|振动|实验室IEPE加速度计＋兼容调理|ADXL1002单轴模拟传感器及板卡|带宽、量程、噪声、刚性安装、供电及输出调理|
|电流|实验室隔离霍尔测量模块|ACS758系列等隔离霍尔候选|量程覆盖工作及启动电流、带宽、零偏、接口与校准|
|温度|K型热电偶＋采集模块|K型热电偶＋MAX31856类读出模块|冷端补偿、测点、固定、响应、环境温度同步|
|转速|光电转速或编码器|光电脉冲传感器＋计数输入|脉冲/转、采样时刻、轴端与目标轴承转速映射|
|负载|动态扭矩传感器＋可调制动装置|借用台架，或先标定的低成本负载方案|额定转速/扭矩、输出、安装对中与独立负载证据|
|高频采集|共时钟同步多通道DAQ|AD7606B外置ADC＋STM32H743控制板|同采样边界、输入范围、抗混叠、缓冲、传输与驱动|
|处理与存储|现有Windows电脑＋Python|暂不采购推理MCU|硬盘、原始波形记录、时间戳、版本追溯|

优先复用实验室设备。自建路线会增加传感器调理、PCB/布线、ADC驱动、固件和时间同步工作，需评估工期后选择；不是把开发板接上就能完成高频采集。数字低频IMU若有效带宽不足，不适合作为高速早期轴承频谱分析的等价替代。

推荐首阶段单轴振动＋一路母线电流＋扭矩模拟量，共至少3路同步模拟输入，另外转速脉冲和低频温度；可优先选8路采集以保留三轴扩展。若使用IEPE，DAQ须支持IEPE激励或另配调理器；霍尔输出、扭矩输出的量程/偏置须与ADC匹配。不同类型信号不能直接共接同一输入配置。

## 四、采样与窗口初选

- 振动与电流初选25.6 kS/s/通道、16 bit量级、硬件共时钟。该采样对应奈奎斯特12.8 kHz，实际可用带宽更小，须留抗混叠过渡带并匹配传感器带宽。若目标频带不在此范围或PWM干扰严重，应调整采样/滤波，不能机械照搬。
- 温度初选1—10 Hz，记录真实采样与响应；按窗口边界取均值、末值和趋势，不插值成虚假的高频信息。
- 转速用脉冲计数或时间间隔，保留真实采样时间；负载尽量独立用扭矩而非完全由电流反推。若只能估计负载，应验证故障引起电流变化被校正掉的风险。
- 短信号窗初选2秒、步长1秒；基础FFT间隔约0.5 Hz，真实分辨还取决于窗函数、噪声与转速变化。先做即时诊断，再建分钟级历史分析慢速趋势。
- 当前Demo每步是一分钟模拟特征、历史16步。新短窗或新增频域特征不能直接喂入原模型，需明确特征顺序、单位、时间尺度并重新拟合/训练。

仅两路25.6 kS/s、16 bit原始数据的负载约102.4 kB/s、0.37 GB/h（十进制，不含元数据）。三轴振动＋一路电流约0.74 GB/h。磁盘方案须留足重复试验与原始证据容量；后续边缘可保存特征与异常前后原始片段。

## 五、机械平台与测点

机械链：电钻固定夹具 → 联轴器 → 动态扭矩传感器 → 制动器/可控负载装置。设计前核对所有部件的额定转速、扭矩、对中要求与夹持刚性，设置旋转部件防护和可达停止控制。逐步试采而非直接高负载连续运行。

振动测点优先靠近目标轴承的刚性位置，固定方向和安装方式；工具塑料外壳与金属轴承座传递不同，须记录并验证。温度在可达轴承座/外壳表面，同时记录环境温度，不能称表面热电偶读数为轴承内圈温度。电流初期测低压供电母线，提取均值、RMS和纹波；不照搬交流电机供电基频谐波特征。若为PWM驱动，先查看波形与频谱，避免驱动开关被混叠成机械故障特征。

卡盘/输出轴转速不一定等于电机目标轴承转速。记录齿轮减速比、目标部位和可获得的反馈；故障特征频率计算需正确轴速和轴承几何参数，不能预设100或200 Hz就是故障频率。

## 六、试验与标签方案

先确认健康样本与稳定工况，试采后确定3个可重复转速区间和3个负载区间。工况组合须在设备可控且安全允许范围，电钻转速会随负载变化，按实际测得值记录而非只贴设定值。

健康/确认缺陷样本通过拆检、部件来源、游隙或其他可获得测量证据确认，保留照片和测量记录。四级“正常/轻/中/重”必须有独立分级标准；条件不足时先采用健康/确认异常，不能按模拟运行时长生成真实磨损标签。缺陷样本分类不等于自然磨损寿命轨迹。

建议分阶段采集：
1. 健康条件矩阵：稳定运行、启停、负载切换；每工况重复，记录热稳态与前后工况。
2. 机器异常矩阵：确认轴承缺陷在同工况下重复观测，并保持其他部件与安装条件尽量一致。
3. 采集异常矩阵：对原始记录做明确标注的丢包、噪声、时间偏差注入；另记录安装问题/饱和等实测情况。离线注入与实测分别报告。
4. 维修矩阵：有效更换、维修不充分、仅换传感器、负载改变。可比工况复测及独立健康确认决定参考更新资格。

尽量获取多台独立设备/部件样本；具体数量按资源讨论。若只有一台，报告同台可重复性，不宣称跨设备泛化。先按设备或独立部件/完整运行轨迹分组，再生成重叠窗口；不能只按窗口随机7:2:1切分。

数据字段至少包含设备/部件/运行段ID、采样开始结束、率与单位、序号、安装/校准、转速/负载/模式、环境温度、质量证据、独立标签来源与审核、维修操作、模型与基线版本。保存原始波形和处理参数以便追溯。

## 七、算法路线与候选准入规则

第一层：一致的因果预处理、窗口特征与质量标志。振动RMS/峭度/频带能量，电流均值/RMS/纹波，温度温差/趋势；包络、阶次根据频带、转速和轴承参数选用。

第二层：已确认健康数据拟合条件参考，输出相对于同工况正常水平的残差；线性回归为起点，若残差仍随工况显著变化，再考虑分段或稳健/非线性参考。保留原特征与工况用于排查过度校正。

第三层：规则、简单特征分类器与小型LSTM作为基线，质量约束融合作对照。Transformer-LSTM为已有结构对照，只有在相同划分和资源指标上显示必要性才增加复杂度。

第四层：新增联合准入。候选输入包括工况覆盖、转速/扭矩变化、稳定持续时间、缺失/饱和/平线/同步误差、有效通道组合与通道恢复状态。分别控制诊断证据和健康学习：数据可用于判断不等于可学习为健康。

准入条件的稳定时间、有效通道阈值、工况距离与恢复条件均为待验证参数，只能在训练/验证数据选择。对未知或不足输出原因，不把冻结当健康；限制等待造成的延迟，并保留可靠通道明确危险征兆的及时处理。质量指标不能仅因振动幅值大而降低权重。

维修后新运行段＋独立检查＋可比工况复测生成候选健康参考，使用留出的健康工况和已确认故障记录验证覆盖与灵敏度，通过才启用新版本，失败冻结/回退。这个完整机制尚未在现有代码实现。

第五层：持续退化轨迹、失效终点和删失样本处理明确后才增加RUL；目标硬件确定后再考虑量化、蒸馏或结构压缩，并测精度、端到端延迟、峰值RAM和能耗。

## 八、对照实验与验收

诊断对照至少包括：原始特征固定阈值；按负载动态阈值；条件健康参考＋同一预测器；真正等权融合；质量约束融合；新增联合准入；维修后直接更新与受控更新。

已有fixed_fusion对照保留了可学习门控，只去掉质量连续乘子，不能作为真正等权对照。新实验需要补真正固定融合。分类任务保持一致：若比较阈值二分类与网络，网络输出须映射相同健康/异常任务并用验证集定阈值，不将二分类准确率与四分类直接比较。

在同故障召回目标下比较每100运行小时误报警事件数、检出延迟、有效覆盖率；报告各类召回和设备间波动。维修场景比较残余故障是否被吸收、更新后的灵敏度、参考偏移与回退成功率。拒绝更多窗口可以少报，因此不可单看误报下降。

采集验收：校准可追溯、同步误差已测、采样/缓冲无未标注丢包、单位与安装明确、原始记录可读取。模型验收：设备与轨迹不泄漏、覆盖与异常有效性明示、效果可重复。专利交底验收：机制可计算可实施、图与实现一致、效果与数据来源明确。

## 九、请老师确认的资源与取舍

是否有IEPE、同步DAQ、动态扭矩和负载装置；是否能获得可拆检电钻和确认缺陷部件；是否同意RUL后置；台架与真实电钻的验证边界；是否优先联合证据准入并将维修机制作为延伸；下一阶段数据规模与交付时间。报价与最终采购BOM在资源确认及手册核验后形成。
