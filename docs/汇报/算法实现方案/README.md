## 讲解顺序

1. **比较正常水平**：参考转速和负载，比较当前信号与同工况正常水平的差异。
2. **综合三种信号**：利用已有质量分数调整贡献，综合振动、电流和温度信息；并非独立传感器故障分类器。
3. **观察连续变化**：联系前后测量，分析变化趋势。实际使用Transformer关联历史窗口，再由LSTM汇总趋势。
4. **输出仿真结果**：分别得到状态、健康程度和仿真寿命范围，接入网页及告警、工单和复测流程。

可以这样向老师讲：“我先让算法参考当前转速和负载，比较信号与正常水平的差异；再结合三种传感器和数据质量，观察连续变化，最后给出状态与健康程度等仿真结果。目前完成了流程演示，真实工具的健康等级与寿命还需要实测验证。”

## 当前进度

仿真模型：16窗×6维特征及工况、质量 → 健康工况基线残差校正 → 三个分支编码与质量门控融合 → 1层32维2头Transformer → 1层32维LSTM → 仿真状态／HI／RUL三分位数。模型17789个参数，仍为标准注意力。

公开数据使用另一条轴承模型：处理后的单通道振动 → 轻量CNN → ELU+1核线性注意力 → 均值池化／正常、内圈、滚动体、外圈分类。默认模型5876个参数。它是故障部位分类预验证，未给出真实磨损等级或寿命预测。

下一步需采集真实工具多源同步数据，验证健康等级和寿命。完整限制及实验指标保留在讲者备注，另见[模型说明](../../phase2/模型结构与计算过程.md)与[实验报告](../../phase2/公开轴承模型实验报告.md)。
