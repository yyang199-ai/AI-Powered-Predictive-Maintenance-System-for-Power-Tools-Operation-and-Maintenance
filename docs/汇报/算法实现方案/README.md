## 可以怎么讲

原来的仿真Demo有Transformer。它先校正工况变化，再按照传感器质量融合振动、电流和温度特征；Transformer关联历史窗口，LSTM汇总变化趋势，最后分别输出状态、健康指数和仿真寿命区间。这些结果接入网页，展示告警、工单及维修复测流程。

公开数据预验证使用另一条模型：经过处理的轴承振动波形进入轻量CNN，再经过线性注意力和分类器，识别正常、内圈、滚动体及外圈故障。它帮助验证真实振动分类，但未提供真实磨损等级、健康指数或剩余寿命。

下一步需要真实工具同步多源数据，用这些数据训练和验证健康与寿命模型。现阶段可以汇报算法原型、公开数据预验证和发现的问题。

## 实际结构

仿真链：16窗×6维特征及工况、质量 → 健康工况基线残差校正 → 三个2→32维分支编码 → 质量与工况门控融合 → 位置与工况信息 → 一层32维、2头Transformer → 一层32维LSTM → 四档仿真状态／HI／RUL三分位数。模型17789个参数，仍为标准注意力。

公开链：1×1024振动波形 → 1D卷积及深度可分离卷积（8×256→16×128→24×64） → ELU+1核线性注意力 → 均值池化 → 四类故障部位分类器。默认模型5876个参数，验证集选型；FFT特征表用于解释，不是当前输入。

线性注意力降低的是注意力核心计算的序列长度依赖，不等于整个系统必然更快；CPU实验尚未证实稳定整体加速，MCU与70%指标未验证。公开数据正常留出记录识别仍差，详见讲者备注及[模型实验报告](../../phase2/公开轴承模型实验报告.md)。
