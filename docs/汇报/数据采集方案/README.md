# 拟定数据采集方案：PPT讨论页

- [一页可编辑PPT](数据采集方式_讨论版_可编辑.pptx)
- [PNG图片：可直接插入PPT](数据采集方式_讨论版_图片.png)
- [PDF预览](数据采集方式_讨论版_可编辑.pdf)

正文列出振动、电流、温度、转速及负载的采集设备和测量方式，下方为传感器至电脑的采集链路。所有内容均为原生文字和形状，正文21磅，没有页脚、角标或边缘说明。

在PowerPoint中打开可编辑版，复制整页或选中全部形状复制到汇报PPT；也可通过“插入 → 图片”插入PNG。讲者备注保留同步、选型、标注和当前进度说明。

具体工具与目标部件尚未确定，本页用于讨论采集方案。传感器量程、频带、供电和采集接口需匹配；振动、电流优先共时钟采集，温度按采样时间对齐。负载实测值与加载设定值分别记录，外壳温度不等同部件内部温度。当前尚未完成自有电动工具的实测采集。
