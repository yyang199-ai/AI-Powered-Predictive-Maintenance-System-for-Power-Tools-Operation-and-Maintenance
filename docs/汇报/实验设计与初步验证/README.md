## 第一页可以怎么讲

“目前搭建的是虚拟实验平台。我可以选择工具、负载、转速和损伤设定，生成振动、电流、温度信号。先固定其他条件，只改变一个因素，观察信号如何变化。目前已经生成48组受控仿真记录，跑通信号处理和导出流程，用它来设计后续真实实验。”

截图单次设置：电钻、中度（虚拟）、75%负载、1800r/min、2秒、25℃、seed42。批量48组由三工具×四档生成等级×两负载（25%/75%）×两种子（42/43）组成。仿真标签由生成器设置，不能作为真实磨损或分类精度证据。

## 第二页可以怎么讲

“我还使用公开的CWRU轴承振动数据进行算法预验证，共40条记录，按记录分成28条训练、8条验证、4条测试。比较三种模型后，验证集选定的线性注意力模型测试准确率为81.38%。但正常测试记录误报率达到95.76%，说明目前模型还存在问题。截图中就有一个正常窗口被判断成滚动体故障，后续需要分析误判、补充数据，并开展真实工具验证。”

95.76%的支持是1条正常记录的118个重叠窗口，不代表对所有正常工具的总体误报率。全部测试827个窗口也不是827个独立设备。该模型验证的是故障部位识别，尚未验证真实工具磨损等级和剩余寿命。

更完整的数据划分、参数、指标、计时与限制位于讲者备注及[公开轴承模型实验报告](../../phase2/公开轴承模型实验报告.md)。虚拟平台说明见[实验台设计](../../phase2/虚拟实验台设计.md)。本次仅操作已有网页并制作汇报材料，没有修改算法、重训模型或接入实物。
