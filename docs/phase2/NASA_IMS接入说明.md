## 文件在哪里

- `data/public/NASA_IMS/raw/run2/`：云工作区内的完整原始 ASCII 文件；Git 忽略该目录。
- `data/public/NASA_IMS/prepared/features.csv`：3936 行，每行是一份快照中的一个轴承；仓库提供，打开网页即可使用趋势。
- `data/public/NASA_IMS/prepared/dataset_manifest.json`：来源、完整性、预处理方法、标签范围及文件校验值。
- `predictive/ims_data.py`：导入、预处理、生成和读取功能。
- `scripts/prepare_nasa_ims.py`：Windows／Linux 共用的命令行入口。

`features.csv` 中的 3936 行来自同一次试验的 984 次采集，并非 3936 台独立设备；一次试验中只有一个有终点故障说明的轴承。

## 怎么使用

网页中进入 NASA／IMS 趋势部分，默认选择轴承 1，看“距首快照的时间”和原始振动 RMS 的变化。可以选轴承 2—4 对照，也可看去噪后 RMS、峭度和 FFT 频率特征。图中幅值沿用原始 ASCII 数据的数值，本次没有独立核实标定单位，不能擅自标成工具的 m/s² 或 g。

处理后的 CSV 和清单已经提供，不需要先下载 524 MB 原始文件。如果想在自己的电脑重做预处理，先在项目目录按项目说明安装依赖，然后运行：

```powershell
# Windows，已有 Python 虚拟环境
.\.venv\Scripts\python.exe scripts\prepare_nasa_ims.py --download
```

```bash
# Linux / 云工作区
.venv/bin/python scripts/prepare_nasa_ims.py --download
```

脚本下载固定 Git 提交的约 133 MB ZIP，在本地解出快照，核对完整时间线，计算特征并重新生成清单。下载和原始文件合计需预留约 700 MB 空间。可指定目录：

```powershell
.\.venv\Scripts\python.exe scripts\prepare_nasa_ims.py --raw-dir "E:\轴承数据\IMS\run2" --output-dir "E:\轴承数据\IMS\prepared"
```

上述命令将已有的 984 个时间戳命名 ASCII 文件放在同一目录导入，不要求再下载。若目录只包含一部分，可加 `--allow-partial` 做特征探索；部分导入会明确标为 `partial_import`，不会生成末端倒计时标签。

## 预处理和标注是什么

1. 校验文件名、完整时间线、每份文件的行列数及数值有效性。
2. 分离 4 个轴承的振动通道。每个快照独立处理，去均值去除直流分量。
3. 六层 Haar 小波分解，使用最细层细节的 MAD 估计噪声，采用通用软阈值再重构。该步骤是离线处理，不宣称可以直接在 MCU 实时运行。
4. 提取去噪 RMS、峭度、峰值因子、峰峰值；加 Hann 窗后作 FFT，计算主峰频率、频谱重心和 0—1、1—5、5—10 kHz 频带能量占比。频带是探索性划分，尚未按轴承几何推导故障特征频率。
5. 同时保留原始 RMS。小波阈值可能削弱脉冲及高频内容，因此应对照原始和去噪趋势，尚不能声称去噪一定提高准确率。
6. 仅对完整数据中轴承 1 生成 `endpoint_proxy_rul_hours`，其计算为“最后快照时间 − 当前快照时间”。轴承 2—4 未提供终点故障，标为右删失，对应倒计时保持空值。

`elapsed_hours` 和末端倒计时是文件时间戳的壁钟差，不是已核实的连续运行小时数。原说明给出最终故障部位，未精确给出物理失效瞬间。本次发现最后 2 个快照的所有通道均为低幅值，因此到最后记录的倒计时尤其不能等同“到真实失效的剩余时间”。

## 末端低幅值如何看

快照 982、983 的所有通道 RMS 均低于各自前 10 次快照中位数的 5%。CSV 的 `activity_status` 将它们标为 `low_activity_all_channels`；这是低幅值观察，尚不能确认是停机、工况变化还是测量链路变化。网页保留这些点并提示，不能把振动突然下降解释为轴承修好了，也不能把它们重新纳入健康基线。

## 目前不能据此证明的结论

这组数据没有电流、温度、电钻负载，也没有正常／轻度／中度／重度的独立磨损标签。本次没有人为按时间比例或 RMS 阈值补造四级标签。

完整试验只有一个已描述故障终点。随机将同一条退化曲线的快照按 7:2:1 分割，容易让训练集和测试集共享同一试验信息，因此本次没有用这种分割宣称 RUL 有效。任务书所需的 7:2:1 故障分类预验证在 CWRU 记录分组中执行；NASA 部分保留完整曲线作探索。

下一步研究寿命预测，应补充独立寿命试验，明确失效判据、停机时间、右删失处理和独立试验划分，再报告 RUL 误差及提前预警指标。这次接入没有验证任务书中的 15% 寿命误差或提前 3—7 天预警。
