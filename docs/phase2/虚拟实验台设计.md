# 原始波形虚拟实验台设计

2026年10月9日。实现入口：`predictive/lab.py`。

## 1. 用途与完成边界

本模块为电钻、角磨机、冲击扳手生成带单位、采样率与时间轴的**模拟原始波形**，用于演示数据采集后的处理步骤，以及验证导出、特征与展示接口。它没有连接真实传感器或机械台架，模型参数未经实测校准。正常、轻度、中度、重度是生成器的设置标签，不是独立测量确认的轴承磨损等级。

模块与已有 `predictive/data.py` 的六特征仿真、已有模型及公开轴承数据分开。即便一些特征同名，也不能把新的真实或模拟波形特征直接送入旧模型：单位、时间尺度、统计分布与特征定义必须对齐，并重新拟合、训练和验证。

## 2. 接口与数据结构

```python
from predictive.lab import create_lab_run, extract_lab_features, export_lab_run

run = create_lab_run(
    tool="drill",                 # drill / grinder / impact_wrench
    damage="mild",                # normal / mild / moderate / severe
    load=0.5,                     # 无量纲，0至1
    rpm=1800,                     # 模拟目标旋转轴转速，非已核实商用工具轴速
    duration_seconds=5,
    seed=42,
)
features = extract_lab_features(run)
paths = export_lab_run(run, "artifacts/lab/example")
```

`LabRun` 保存 `vibration`、`current`、`temperature` 三个一维 NumPy 数组，`sampling_rates` 保存各路采样率，`times` 保存各路相对秒时间轴，`metadata` 保存模拟来源、工具、标签来源、工况、单位、样本数和生成假设。各路共享虚拟起点，但温度以自己的低频时钟采样。

可选关键字 `sampling_rates={"current": 4096}` 覆盖指定通道采样率；未指定通道保持默认。`ambient_temperature_c=25.0` 设置环境温度。输入校验包含工况、有限值、采样率、模拟频带覆盖、最少样本数、时间轴及内存规模。

|通道|默认采样率|单位|时间定义|
|---|---:|---|---|
|振动|25,600 Hz|m/s²|`arange(N)/fs`，共享虚拟起点|
|电流|25,600 Hz|A|同上|
|温度|10 Hz|°C|低频时间轴，不扩展成虚假高频信息|

默认时长5秒；允许0.5至120秒，并要求温度至少4点、高频通道至少64点。总采样点上限800万。默认转速：电钻1800 rpm、角磨机11000 rpm、冲击扳手2200 rpm；输入允许范围分别为60—3600、60—16000、60—4500 rpm。这些范围是生成器约束，不是指定商品额定值。

## 3. 波形生成假设

**振动：** 以转频及其二倍频构造稳定运行成分，幅值随模拟负载变化；损伤增加周期冲击，冲击激发指数衰减的共振响应。冲击重复频率暂设为转频的4.6倍，共振频率按工具设置，再叠加随机噪声。4.6倍不是根据真实轴承几何计算的故障特征频率。冲击扳手另含随负载变化的正常工作冲击，避免把其正常冲击直接等同于损伤。

**电流：** 直流均值由空载项、负载项及损伤附加项组成，叠加转频一至三阶调制和噪声。提取的“电流谐波”是这些**模拟轴转频阶次**，不是交流市电谐波，也没有模拟具体无刷驱动的换相或PWM谱线。

**温度：** 采用 `T(t)=T_ambient+ΔT_equilibrium·(1−exp(−t/τ))+noise`，模拟具有热惯性的升温；负载与损伤提高平衡温升。五秒窗口只能呈现局部温升与趋势，不能据此建立真实寿命关系。

当前一次运行的转速、负载保持恒定，未模拟手持传递函数、商业电钻减速机构、真实传感器调理、饱和、丢包或工况切换。若研究这些因素，需另加明确控制量与真值并单独验证；不将默认干净模拟数据当作数据质量机制的完整证据。

## 4. 正交Haar小波软阈值降噪

实现不依赖 PyWavelets，采用自写的正交Haar离散小波：相邻样本的和、差除以 `sqrt(2)` 产生近似系数与细节系数，最多分解6层。非2的幂长窗口反射填充至下一个2的幂，重构后裁回原长度。

最细层细节估计噪声尺度：`σ=MAD(detail)/0.67448975`；通用阈值为 `λ=σ·sqrt(2·log(N))`；每层细节按 `sign(d)·max(abs(d)−λ,0)` 软阈值，再逆变换。近似系数不阈值。

这是完整窗口的离线处理，不能声称实现了因果在线降噪。Haar、固定层数与通用阈值是可复现的初始方案，可能削弱真实故障高频冲击；必须保留原波形，在真实数据上比较信噪改善与故障检出率，不能仅凭平滑程度评价。现有单元测试证明低频正弦叠加白噪声的特定场景下误差下降，不证明对所有轴承故障都有效。

## 5. 特征计算

振动、电流先经过上述小波处理；原始数组保留不变。频谱采用去均值、Hann窗及实数FFT，幅值以窗函数和校正，DC及偶数长度Nyquist项不做双边翻倍。另以Hann周期图计算功率谱密度。

|特征组|输出示例|含义与边界|
|---|---|---|
|振动时域|`vibration_raw_rms`、`vibration_rms`、`vibration_kurtosis`|原始RMS；降噪后去均值RMS及Pearson峭度|
|振动频域|`vibration_peak_hz`、`vibration_spectral_centroid_hz`、`vibration_fft_resolution_hz`|频谱最大非DC幅值频率、功率加权中心、频率栅格间隔|
|振动频带|`vibration_low_band_power`、`vibration_high_band_power`|以1000 Hz示例分带；不是已确定的电钻故障频带|
|电流|`current_mean`、`current_rms`、`current_ripple`|均值、含直流RMS、标准差|
|电流阶次|`current_harmonic_1_amplitude`至`_3_amplitude`|已知模拟转频整数倍附近FFT栅格的幅值；有窗函数及离栅格误差|
|阶次比例|`current_harmonic_distortion_ratio`|二、三阶幅值合成／一阶幅值；描述性比例，不是标准电能质量THD|
|温度|`temperature_mean_c`、`temperature_rise`、`temperature_slope`|平均温度、末点减首点、线性拟合°C/秒|

特征计算使用实际波形与声明的转速，不读取损伤类别；转速是独立虚拟控制参数。特征返回浮点值字典，没有提供分类或RUL推断。降噪、分带和温度趋势单位写入导出说明，避免把温度°C/秒当作旧模型的一分钟趋势。

## 6. 导出与验证

导出返回 `Path` 字典：`waveforms` 为包含原始数组与各路时间轴的压缩NPZ；`vibration`、`current`、`temperature` 为独立CSV；`metadata` 和 `features` 为JSON。来源字段固定为 `synthetic_raw_waveform_lab`，`is_simulated=true`，损伤来源为生成设置。公开轴承数据不写入此来源，真实实验也不能复用这一来源标记。

`tests/test_lab.py` 检查三工具时间/单位、固定随机种子可复现、损伤与负载引起的电流/温升/振动趋势、FFT转频与阶次、小波的特定噪声改善、NPZ原始数据往返及错误配置拒绝。这些检查用于验证模拟与软件实现，不代表真实硬件验收或专利技术效果实测。

后续真实采集应另建来源、独立标签、同步与校准记录，并以独立设备／部件划分数据。此虚拟台可先演示“波形→预处理→特征”，真实诊断、寿命验证仍需真实数据和新的模型训练。

## 7. 可复现批量模拟实验集

在项目根目录运行：

```bash
python scripts/run_virtual_lab.py --output artifacts/lab --duration 2 --seeds 2
```

默认遍历3种工具×4种生成损伤等级×2档负载（0.25、0.75）×2个随机种子（42、43），共48次受控模拟运行，每次2秒。各工具使用自己的默认轴速。输出 `artifacts/lab/runs.csv` 与 `artifacts/lab/manifest.json`；默认只保留小体积特征汇总，不保存全部原始波形。

如需看每次运行的原始振动、电流和温度，再指定：

```bash
python scripts/run_virtual_lab.py --output artifacts/lab/raw_demo --duration 2 --seeds 2 --save-waveforms
```

此时每次运行在 `runs/<run_id>/` 中保存NPZ、三路CSV及元数据/特征JSON。原波形CSV首列为秒时间轴，第二列为该通道数值；振动、电流与温度采样点数不同，不应直接按CSV行号混为同步采样。`--base-seed` 可改初始随机种子，`--seeds` 是连续种子的数量；例如 `--base-seed 100 --seeds 3` 使用100、101、102，产生72次运行。

汇总CSV采用带BOM的UTF-8，便于Windows Excel打开中文工具/等级名称。主要字段包括 `run_id`、`source`、`label_origin`、`tool`、`damage`、`load`、`rpm`、`seed`、`window_seconds`、三路采样率，以及第5节的20项特征。来源为 `synthetic_raw_waveform_lab`，标签来源为 `generator_setting`；manifest记录生成网格、假设、单位、代码及CSV校验和与软件版本。

**怎样进行受控比较：** 在CSV筛选相同的 `tool`、`load`、`rpm`、`seed` 和 `window_seconds`，仅比较 `damage` 的四种设置；其余控制量与随机噪声保持一致。每个默认批次含12组这样的四等级对照。另可锁定工具、等级、转速、种子，只比较两档负载，以观察正常负载也会改变电流、振动和温升。不同工具的原始数值不能直接当作同一损伤量尺。

脚本在保存汇总前检查唯一运行ID、有限特征、每组对照完整，以及原始振动RMS、电流均值、温度斜率随生成等级的预期递增。这只验证生成公式实现与控制变量，不是独立标签验证、分类准确率或专利效果试验。

**怎样下载和查看：** GitHub项目打开 `artifacts/lab/runs.csv`，可点击下载原始文件并用Excel/WPS打开；在本地项目直接进入 `artifacts\lab\` 打开文件。要查看某次波形，使用上述 `--save-waveforms` 命令并打开对应 `runs` 子目录。manifest的假设和数据来源必须与CSV一起保留，不单独把等级列当作真实磨损证据。

这些48条是模拟运行记录，既不是48台独立设备，也不是48次真实试验。任务书要求的5000组真实多工况样本仍未采集或验收，不能靠增加种子或重复切窗宣布完成；公开轴承实验的标签和指标也应保持独立来源。
