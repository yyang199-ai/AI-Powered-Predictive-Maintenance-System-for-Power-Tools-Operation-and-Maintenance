# 第二阶段验收与公开轴承预验证边界

整理日期：2026年10月9日。依据：用户提供的《发明专利研发任务书：AI预测性维护电动工具运维系统》，第二阶段及“给研究生的执行建议”；当前软件实现与此前查新讨论稿。

## 1. 本阶段可以完成什么

任务书第二阶段（第3—6周）要求建立工具实验平台，采集角磨机、电钻、电动扳手在正常、轻微、中度、重度磨损四种状态下的振动、电流、温度；完成小波阈值降噪、振动FFT、电流谐波、温度趋势特征，以及7:2:1的数据集划分。执行建议明确允许先用公开轴承或电机数据作算法预验证，再补充自有采集。

因此，公开数据工作可作为本阶段的预验证子任务，用来完成真实原始信号导入、预处理、标签审计、分组划分和单振动基线。它不能替代电动工具实物平台或多模态采集。原任务书中“不少于5000组”是总体成果目标，不等同于5000次独立试验、5000个轴承或5000条完整寿命轨迹。

| 任务书要求 | 公开轴承数据可支持的完成项 | 仍需自有工具实验补充 |
|---|---|---|
| 工具平台及四种磨损状态 | 在真实公开振动波形上验证数据处理链路 | 工具、测点、负载台架；独立损伤检查及磨损状态定义 |
| 振动、电流、温度同步采集 | CWRU提供加速度测量及转速/试验工况信息 | 电流、温度、环境与同步采集证据 |
| 降噪、频域及趋势特征 | 可验证振动小波降噪、时域及FFT特征 | 电流谐波、温度趋势及实际采集质量规则 |
| 标注与7:2:1划分 | 可建立来源、文件、标签与不重叠划分清单 | 独立工具/轴承身份，真实磨损及维修复测标签 |
| 状态及寿命模型基础 | 可做故障类型识别；缺陷直径任务仅作探索 | 真实健康评分依据、完整寿命终点、未来使用条件 |

建议汇报：“已从纯仿真扩展到公开实测振动数据预验证，建立可追溯的数据处理与分类基线；工具实物、多模态与真实寿命仍需后续验证。”只有相应文件和结果实际生成后，才将该句中的预验证写为完成。

## 2. CWRU的任务与标签边界

CWRU是凯斯西储大学轴承试验资料，常见内容包括正常轴承、驱动端/风扇端的单点人工缺陷、不同负载及转速下的加速度记录。不同位置的DE、FE、BA均为振动观测，不能称为振动、电流、温度三种物理模态。

### 2.1 人工缺陷直径不等于自然磨损程度

目录007、014、021通常对应0.007、0.014、0.021英寸缺陷直径，即0.1778、0.3556、0.5334 mm。实际导入时应保留源标签并核对数据说明。可以研究“正常/不同人工缺陷直径”的区分，但不能直接将其命名为轻微、中度、重度自然磨损。

缺陷位置、形状、外圈角度、负载、传递路径和传感器测点都会改变信号。直径较大不保证全部振动指标单调增加，也不证明剩余寿命更短。不同直径的独立人工缺陷试验不是同一轴承随时间发展的退化轨迹。

建议首个基线使用明确的故障类型标签（正常、内圈、滚动体、外圈），与原Demo的四种模拟磨损阶段分开记录。若使用正常及三种缺陷直径四分类，应明确称为“人工缺陷直径标签分类”；控制故障类型、外圈角度和负载，报告每一组合覆盖，避免把这些因素的差异误当作损伤程度。

### 2.2 四类输出各自说明什么

| 输出任务 | 可以说明的内容 | 不能自动推导的结论 |
|---|---|---|
| 故障分类 | 在给定数据划分下识别正常/故障位置等标签 | 真实电钻诊断精度或磨损严重程度 |
| 受损标签/直径分类 | 在已知人工缺陷条件中区分源标签 | 自然磨损等级、故障发展速度或寿命 |
| 健康状态或分数 | 按明确规则描述相对正常偏离 | 经实测校准的健康百分比或故障概率 |
| 剩余寿命RUL | 需完整轨迹、失效终点和预测时刻定义 | 由CWRU缺陷类别换算寿命小时、天数 |

CWRU不提供本项目所需的同步电流和温度，也不提供从健康到失效的自然寿命轨迹。不得从振动或类别标签合成电流、温度再宣称多传感器效果；不得用“直径越大寿命越短”的人为公式作为真实RUL标签。需要演示这些输出时，保留原仿真模式，并清楚标记数据源。

## 3. 数据划分必须先确定独立单位

### 3.1 先分组，再切窗

7:2:1是比例目标，数据独立性比精确凑足比例更重要。应先为原始记录确定物理轴承、试验运行、原始文件等身份，再分配训练/验证/测试，最后分别切窗。不能把同一原始文件的重叠窗口随机打散到三份集合，也不能让同一波形的复制版、不同通道副本或增强版本跨集合。

最低限度采用文件级划分，保留三个文件清单并检查交集为空。若能识别同一物理轴承或同一试验运行，其全部相关文件必须作为一组。设备编号不能用窗口序号代替；一个MAT文件也不应默认等于一个独立轴承。

CWRU同一人工缺陷轴承在不同负载下可能被反复测量。即使文件名不同，训练与测试仍可能分享同一物理损伤、安装和台架传递路径。因此文件不重叠只能支持“留出记录验证”，不能自动支持“独立轴承泛化”。资料不足以确认身份时，记录为未知，保守说明相关性。

### 3.2 比例、类别覆盖与小组数的冲突

若使用40个文件，28/8/4可构成文件数的7:2:1；但不保证各类别、负载与物理轴承均独立。同一缺陷配置四负载文件若必须同组，组数会远少于40。正常轴承尤其可能只有少数物理实例，不能为保证每一集合都有正常类而拆开同一物理组并称严格独立。

报告至少区分：文件级预验证、按缺陷配置/物理轴承分组验证、留出负载验证。某种划分不能覆盖全部类别时，说明限制或补充独立数据，不用随机窗口填补。留出负载可以单设实验，按其实际比例报告；不必强行同时满足7:2:1与所有工况条件。

### 3.3 防止处理过程引入泄漏

- 标准化尺度、特征筛选、降噪超参数及阈值只使用训练数据确定；验证用于选择，测试仅用于最终报告。
- 数据增强只发生在训练集，原始波形及其增强版本保持同组。
- 连续记录若另做时间段验证，应无重叠，设定隔离区，覆盖输入窗与序列历史；这种划分仍不是独立轴承验证。
- 检查重复内容、文件身份、同一缺陷配置与载荷。保留原始记录ID及窗口起止索引，使任何训练样本可回溯。

结果应同时列出窗口数、原始文件数、可确认的试验运行数、独立轴承数或其未知状态，以及各集合的类别/负载分布。一个长记录可以切出数千窗口，但不能增加物理轴承数量。置信区间和重复实验应以独立记录或轴承为单位，避免把高度相关窗口当作独立重复。

## 4. 预处理与评价口径

每个记录清单至少包括数据集、原始文件名、源URL、SHA-256、通道、单位、采样率依据、RPM、负载标签、故障位置、缺陷直径、外圈角度、组ID及划分。MAT变量中没有采样率时，不能靠目录名或数组长度随意推断。正常与故障记录的采样率可能不同，尤其需要核查正常DE记录与12k故障DE的匹配；统一采样率时保留抗混叠重采样记录。否则采样率、窗长或采集格式可能成为类标签线索。

固定物理窗长和输出采样率后，比较原始/小波处理的时域与频域特征，记录小波基、层数和阈值规则；FFT记录窗函数、频率轴及幅值定义。对比应在相同分组、特征和模型条件下进行，不能只看“滤波后更平滑”。若声称在线处理，还要说明每次处理实际可见的历史范围、缓存和延迟。

首个公开数据基线可采用RMS、峭度等时域和FFT频带能量等特征，使用简单分类器建立可解释起点。报告整体准确率、宏平均F1、各类召回与混淆矩阵，以及文件/组层面的汇总。没有连续真实报警标签时，不将窗口分类错误率直接当作现场误报率、检出延迟或维修预警天数。

## 5. NASA IMS的补充价值及边界

IMS轴承资料由辛辛那提大学相关团队提供，并收录于NASA预后数据资源；它包含运行至故障的振动记录，适合研究退化趋势和寿命任务定义。本次另取得第三方镜像中的原数据说明PDF：其第1—2页记载2000 RPM、6000 lbs径向负载，三个试验，20 kHz采样、每条20,480点，第一组8通道、后两组4通道，并说明时间戳的大间隔可能表示次工作日恢复试验。20,480点在20 kHz下约1.024秒，应保留实际点数和采样率；停机间隔不能无条件累计为有效运行寿命。说明资料与原始波形分别记录来源；当前完整run2的取得和核验状态见第8节。它与CWRU的人工缺陷分类用途不同。即使取得IMS，也不能把时间戳、最后一条记录或异常阈值直接当作所有通道共同的真实失效标签。

使用前需核对试验批次、轴承/通道映射、故障发生位置、采集间隔、停机条件和末端诊断，区分发生故障与未确认故障的轴承。寿命模型应按完整试验或物理轴承分组，并明确使用“到规定试验终点的剩余时间”还是“到实际失效的剩余时间”；两者不得混写。定工况台架结果不能直接支持变工况电钻、未来使用强度、提前3—7自然日提醒，也不能补齐同步电流和温度。

## 6. 与候选创新机制的关系

公开轴承预验证能帮助检查特征提取、工况输入和故障证据是否被保留，但不能证明本项目候选创新已成立。

| 研究机制 | 本次预验证可做的检查 | 仍缺少的证据 |
|---|---|---|
| 工况校正 | 对比有/无负载或转速信息，检查故障召回 | 电钻独立负载来源，真实启停/负载切换及过度校正测试 |
| 质量与工况共同控制准入 | 人为设缺失/截断等扰动，区分原始测试与扰动测试 | 实际饱和、安装异常、同步误差的独立质量标签 |
| 维修后参考受控恢复 | 只能测试软件流程与已知场景的规则 | 实际维修前后、独立健康确认、可比工况、验收及回退 |
| 多模态融合与RUL | CWRU仅支持振动及工况相关预验证 | 同步三模态、完整寿命与真实部署证据 |

人工扰动是模拟观测异常，不等于实际传感器异常样本。去除质量较差输入可能降低误报，也可能丢失真实故障，需同时报告故障召回、可用覆盖率、拒绝比例和延迟。已有文献与专利覆盖工况参考、分支融合、时序网络和重标定，完成公开数据基线不等于获得了新的专利技术贡献。

## 7. 可审阅的阶段交付与完成标记

建议将交付分成两类，按产物实际存在情况验收：

1. **公开数据预验证**：来源与下载清单、哈希及标签审计；分组/文件划分；真实振动预处理；可复现单模态基线；评价结果及其适用范围。
2. **自有工具实验准备/采集**：平台与传感器连接记录、同步及标定、独立磨损/健康标签、原始三模态与工况、工具级划分；完整寿命与边缘性能另列验证。

只有第1类完成时，写“第二阶段公开数据预验证完成，工具采集部分待完成”，不能写“第二阶段全部验收通过”。准确率≥92%、寿命误差≤15%、算力下降70%、MCU≤100 ms及提前3—7天提醒继续列为待验证目标，不能用公开数据窗口分类的单个指标替代。
