# 公开轴承数据怎么使用

本轮已把 **CWRU（凯斯西储大学）实际轴承振动数据**接入项目作为默认算法预验证数据。你下载当前项目后可以直接打开网页、选择记录、查看故障分类；不需要先重新下载原始文件或训练模型。原来的虚拟电钻数据只用于单独的仿真实验和维修流程演示。

## 已经准备好的数据

选取正常轴承 4 条记录，以及驱动端轴承内圈、滚动体、外圈人工缺陷各 12 条记录，共 **40 个完整 MAT 记录、9,346 个窗口**。负载为 0、1、2、3 hp；故障数据采用驱动端 DE 通道、12 kHz 实验组；外圈只使用 6 点钟位置，避免把不同缺陷方位混为一个实验条件。

| 文件 | 用途 |
|---|---|
| `artifacts/bearing/data/dataset.npz` | 可直接训练或推理的实际振动窗口，约 7.4 MB |
| `artifacts/bearing/data/features.csv` | 每个窗口的标签、工况、时域/FFT/包络谱特征，Excel 可直接打开 |
| `artifacts/bearing/data/records.csv` | 40 条原始记录的负载、转速、缺陷尺寸、分割、下载地址和校验值 |
| `artifacts/bearing/data/dataset_manifest.json` | 预处理规则、样本数、分割说明和准备后文件的 SHA256 |
| `data/public/CWRU/manifest.json` | 逐个原始 MAT 文件的来源、实际通道键和下载字节校验 |
| `data/public/CWRU/raw/*.mat` | 本云工作区下载的原始 MAT；体积较大，不随 GitHub 源码提交，可用脚本重取 |

数据原出处为 [CWRU Bearing Data Center](https://engineering.case.edu/bearingdatacenter)，实验装置为带测功机的 2 hp 电机轴承试验台。最初官网无法连接时，从公开原格式 MAT 镜像取得文件，固定镜像 commit 为 `0d07cb1caf0a5a68a955c2f43cfc21b9a208406a`。官网连接恢复后，**40 个文件逐一从官网再次下载，SHA256 全部与镜像相同**。这些校验对应本次下载的具体字节，不代表 CWRU 出具的认证。

## 标签到底代表什么

模型的任务是四类故障位置分类：`0=正常、1=内圈缺陷、2=滚动体缺陷、3=外圈缺陷`。

故障直径由原始实验提供：0.007、0.014、0.021 英寸，分别为 **0.1778、0.3556、0.5334 mm**。网页把它们写成“小尺寸人工缺陷、中尺寸人工缺陷、大尺寸人工缺陷”，用于解释所选测试记录。尺寸来自数据集标签，不是模型预测，也不等于电钻的轻度、中度、重度自然磨损。

这些记录是电火花加工出的单点缺陷样本，没有自然退化过程或最终失效时刻。因此本公开数据分类器**不输出剩余寿命、健康指数或维修后的恢复结果**。该批数据也没有电流、温度通道，不能用生成的电流、温度冒充同步实测信号。网页中的三传感器工具实验使用明确标识的独立仿真模式。

转速优先取 MAT 中的 RPM 字段。正常记录中部分文件没有 RPM 元数据，采用官网工况表的近似转速；`rpm_source` 列说明来源，避免把标称值称作实测值。振动单位保留“数据集加速度原单位（未独立校准）”，不据此计算真实工具的振动安全限值。

## 数据处理按什么顺序完成

1. **选完整记录与通道。** 按原始编号准确选取 `Xxxx_DE_time`；正常文件中重复出现的其他记录不混入该记录。如果通道不唯一且无法确定，脚本报错。
2. **统一采样率。** 故障实验用 12 kHz。正常记录按学术开源项目 [openConMo 的正常数据映射](https://github.com/Aalto-Arotor/openConMo/blob/d2924b6683f1ba49661fae63df963d71efa10c15/scripts/CWRU_download.py#L318)采用 48 kHz，先使用 `scipy.signal.resample_poly` 做抗混叠低通与 4 倍降采样，再统一为 12 kHz。引用固定 commit `d2924b6683f1ba49661fae63df963d71efa10c15`，属于二级资料解释依据；正常官网表格及 MAT 未逐文件给出采样率，文件 SHA 一致也不能证明该元数据。清单的 `normal_sample_rate_basis` 保留出处与局限，真实硬件接入必须提供实际采样率。
3. **切窗与小波降噪。** 每窗 1,024 点（约 85.33 ms），步长 512 点（约 42.67 ms）。每个已完成窗口独立去均值，再用三级 Haar 小波软阈值降噪。噪声标准差按最细层细节系数的 MAD 估计：`sigma = MAD / 0.67448975`；阈值为 `sigma × sqrt(2 × ln(1024))`。此过程不读取其他窗口或未来记录。
4. **提取可检查的特征。** 保存 RMS、峭度、峰值因子、峰峰值；Hann 窗 FFT 的峰频、谱质心、谱熵和 0–1、1–3、3–6 kHz 频带能量占比；另保存 Hilbert 包络谱峰频。FFT 频率分辨率为 11.71875 Hz。这些特征便于分析和基线分类器使用；神经网络输入为处理后的振动波形。
5. **记录级分割与训练标准化。** 先确定完整记录的分组，所有同记录窗口只进入同一分区。保存的波形没有逐窗幅值归一化，以保留振动强弱信息；模型训练器只用训练集拟合全局均值、标准差，验证和测试复用冻结参数。

按任务书的 **7:2:1** 进行记录数分割：训练 28 条、验证 8 条、测试 4 条，各分区都包含四类故障。由于原记录长度不同，对应窗口数为 **6,625 / 1,894 / 827**，窗口比例不是精确 7:2:1。

重叠窗口彼此相关，不是 9,346 次独立实验。相同人工缺陷配置在不同负载文件中可能使用同一个物理轴承，因此文件隔离**不能称作独立轴承或跨设备验证**。另提供完整负载 3 留出的补充实验：10 条负载 3 记录测试，负载 0/1/2 的其余 30 条按类别分为 23 条训练、7 条验证。这用于检查跨负载表现，仍不证明从轴承台架迁移到电动工具的效果。

## 你怎样直接用

网页默认“公开轴承数据预验证”。选择测试记录后，点击开始或逐窗前进；“已知实验标签”解释数据来源，“模型判断”显示分类结果。页面显示的是已去均值、降噪的振动片段及频谱，不能称为原始传感器波形。需要比较算法时查看训练报告；不要把单个好看的窗口作为全模型准确率证据。

Python 中读取准备好的数据：

```python
import numpy as np

with np.load("artifacts/bearing/data/dataset.npz", allow_pickle=False) as data:
    train = data["split"] == "train"
    X_train = data["X"][train]     # [窗口数, 1通道, 1024采样点]，float32
    y_train = data["y"][train]     # 四类故障位置标签
    records = data["record_id"][train]
```

NPZ 还提供 `load_hp、rpm、defect_diameter_mm、start_seconds`。这些是记录的实验元数据；不要把故障尺寸、真实标签作为分类输入，这会造成标签泄漏。`raw_example` 保留一条真实 12 kHz 的未降噪窗口，供测量“预处理→标准化→推理→分类解码”的 CPU 延迟。

重新下载并重做同一预处理（在项目根目录、已安装项目依赖的 Python 环境中执行）：

```text
python scripts/prepare_public_data.py
```

该命令用 `curl` 拉取固定版本数据，记录 SHA256，校验官网与镜像，再生成三个数据文件和清单。现代 Windows 自带 `curl.exe`。已下载好原始 40 个 MAT 后，可离线重复准备：

```text
python scripts/prepare_public_data.py --offline
```

本次 9,346 个公开窗口用于算法预验证，不等于任务书要求的 5,000 组自采电动工具多工况数据已经完成。后续要采集电钻实际振动、电流、温度、转速和负载，记录部件型号与故障证据，再验证四级磨损、寿命预测及维修闭环。
